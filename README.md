## 概要
Recursion (https://recursionist.io/) のカリキュラムが変更されたので、再度Markdown to HTML Converterを作成しました。<br>
前回作ったものはこちら: https://github.com/HikaruCS/Markdown_to_HTML_Converter

## 操作方法
次のコマンドで、input.mdの内容をoutput.htmlに変換できます。
```
python3 md_to_html.py <input.md> <output.html>
```

## 注意
- とりあえず動くものを作ることを目的に取り組んだため、バリデーションなどのストレッチ課題はやっていません。
